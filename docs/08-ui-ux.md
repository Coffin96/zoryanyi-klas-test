# 08. UI/UX

## 1. Принципи

- Дитина розуміє екран за 5 секунд: одне велике число (баланс) і три смуги прогресу.
- Вчитель виконує дію за один скан і 1–2 дотики; жодних діалогів підтвердження для видачі (є скасування).
- Mobile-first (учень 360–430 px; вчитель телефон, планшет або ноутбук).
- Мова українська; ніяких «магічних» чисел у коді, усі тексти з `src/i18n/uk.js`.
- Без випадковості, без рейтингів, без порівнянь між дітьми.

## 2. Візуальна тема «зоряна ніч» (стилістика Genshin Impact)

Застосунок оформлено у фірмовій фентезійній естетиці Genshin Impact: глибоке астральне нічне небо (Celestial Night), контрастні теплі пергаментні картки Книги Шукача Пригод (Warm Parchment), золоті філігранні обрамлення (Gold Trim), латунні треки прогресу з анемо-бірюзовим сяйвом та кнопки в стилі золотих злитків та багряних стрічок.

### 2.2. Типографіка

- **Заголовки та акцентні цифри (`--font-fantasy`):** `'Cinzel', 'Marcellus', 'Trajan Pro', 'Palatino Linotype', 'Book Antiqua', Palatino, Georgia, serif`. Використовується для заголовків екранів, великих лічильників балансу, рангу та кнопок оцінок.
- **Основний текст (`--font-family`):** системні шрифти (`system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`), без зовнішніх залежностей.

### 2.3. Нативна векторна графіка (`src/components/genshin-icons.js`)

Замість системних емодзі використовується набір автономних легких SVG-іконок та орнаментів, вбудованих у код:

1. **`iconPrimogem(size, className)` (Примогем ✦):** 4-променева діамантова зірка з багатошаровим золотим градієнтом, фасетками та білим ядром. Головна валюта та символ застосунку.
2. **`iconMoraPouch(size, className)`:** мішечок мори / скарбів для вкладки «Магазин».
3. **`iconCompassQuest(size, className)`:** компас шукача пригод для вкладки «Квести».
4. **`iconChronicleScroll(size, className)`:** сувій стародавніх хронік для вкладки «Історія».
5. **`iconArcaneQr(size, className)`:** арканний гліф / рунічна матриця для вкладки «Мій QR».
6. **`iconRankCrest(levelNum)`:** філігранний 8-кутний герб рангу учня з сапфіровим щитом та золотою окантовкою.
7. **`iconFiligreeDivider()`:** витончений горизонтальний філігранний розділювач з ромбами `◆ ✦ ◆`.
8. **`iconFlame(size)`:** полум'я для квесту серії (streak) замість емодзі 🔥.
9. **`iconGrowth(size)`:** графік динаміки для квесту зростання (growth) замість емодзі 📈.
10. **`iconContrib(size)`:** символ рукостискання / підтримки для ручного квесту внеску замість емодзі 🤝.

### 2.4. Елементи інтерфейсу та анімації

- **Картки:**
  - `.parchment-card`: світлі пергаментні картки із золотим кантом 1.5px, кутовими діамантовими мітками (45° ромби) та м'якою тінню.
  - `.surface-card`: глибокі напівпрозорі сапфірові картки з ефектом `backdrop-filter: blur(10px)`.
- **Прогрес-бари (`.genshin-progress-track`):** стилізовані латунні треки з внутрішньою тінню та плавним анемо-бірюзовим (`.genshin-progress-fill-cyan`) або золотим (`.genshin-progress-fill-gold`) заповненням.
- **Нижня навігація (`.genshin-bottom-nav`):** фіксована панель з матовим склом (`backdrop-filter: blur(14px)`), золотим підкресленням активної вкладки та мікро-анімацією підйому іконки.
- **Видошукач сканера (`.scanner-overlay`):** темно-астральне поле з прицілом та 4 витонченими кутовими золотими дужками.
- **Клавіатура оцінок:** сітка плиток у стилі сузір'їв / талантів Genshin Impact (`.grades-grid`, `.grade-btn`) із золотим контуром та яскравим золотим сяйвом при виборі.
- **Квитанція / сповіщення (`.receipt-toast`):** плаваюча овальна плашка в стилі офіційних оголошень Genshin з неоновим золотим кантом і сяйвом.
- **Доступність:** при `prefers-reduced-motion` анімації вимикаються; всі цілі дотику ≥ 48×48 px; контраст тексту відповідає стандартам WCAG.

## 3. Екрани учня (`index.html`, PWA)

Навігація внизу: **Мої ✦ · Мій QR · Магазин · Квести · Історія** реалізована через `.genshin-bottom-nav` з нативними SVG-іконками (`iconPrimogem`, `iconArcaneQr`, `iconMoraPouch`, `iconCompassQuest`, `iconChronicleScroll`) та золотим підкресленням активної вкладки.

### 3.1. Мої ✦ (головний)

```
┌──────────────────────────────────────────────┐
│  ✦ Лис-07 ✏️                 [Це не я]       │   ← кнопка виходу в багряному стилі
├──────────────────────────────────────────────┤
│  [Герб Рангу]  РАНГ ШУКАЧА ПРИГОД            │   ← iconRankCrest(levelNum)
│                Учень 3-го рангу              │
│  ✦ 23                                        │   ← велике число балансу + iconPrimogem
│  Сузір'я  ▓▓▓▓▓░░░  до наступного: 57 ✦      │   ← латунний трек з анемо-бірюзовим сяйвом
├──────────────────────────────────────────────┤
│ [Пергамент]  Карамель       7 ✦   [✓]        │   ← .parchment-card, золота рамка,
│              прогрес-бар до кожної або       │     кутові діамантові мітки
│              «ще 4 ✦» / «через 12 днів»      │
│ [Пергамент]  Желейка       12 ✦   [✓]        │
│ [Пергамент]  Тарталетка    17 ✦   [✓]        │
├──────────────────────────────────────────────┤
│ [iconGrowth] Зростання 1/2                   │   ← SVG-іконки квестів замість емодзі
│ [iconFlame]  Серія 0/2                       │
└──────────────────────────────────────────────┘
```

Вимоги: баланс і прогрес оновлюються в реальному часі; для кожної нагороди статус: можна взяти / «ще N ✦» / «знову через N днів» / «закінчилось»; відлік до кінця року, коли лишається ≤ 14 днів.

### 3.2. Мій QR

Великий QR (`P`), псевдонім, підказка «Збільши яскравість». Працює офлайн. Оформлений у темній сапфіровій картці з арканними кутовими елементами (`iconArcaneQr`).

### 3.3. Магазин

Каталог активних позицій у стилі пергаментних карток (`.parchment-card`): іконка/зображення, назва, ціна, латунний прогрес-бар та статус. Кнопка «Показати вчителю» для доступної позиції генерує QR `R` (дійсний сьогодні).

### 3.4. Квести

Оформлення у стилі Книги Шукача Пригод:
- Заголовок із витонченим філігранним розділювачем `iconFiligreeDivider()`.
- Пергаментна картка місячного ліміту із золотим прогрес-баром (`monthStars / monthlyCap ✦`).
- Картки завдань із круглими золотими медальйонами з векторними SVG-іконками:
  - `iconFlame` — квест серії оцінок (streak, замість 🔥).
  - `iconGrowth` — квест зростання балів (growth, замість 📈).
  - `iconContrib` — квест допомоги та внеску в клас (manual/contrib, замість 🤝).
  - Золотий статусний бейдж `+N ✦` (`.badge-gold`) та персональний трек прогресу.

### 3.5. Історія

Останні 20 подій на пергаментних смужках із символікою сувою хронік `iconChronicleScroll`: «+8 ✦ за оцінки», «−7 ✦ Карамель», «+3 ✦ Зростання», «↩ скасовано». Без показу оцінок поштучно за замовчуванням (лише суму).

### 3.6. Квитанція

Тост після події (`.receipt-toast`): «+8 ✦ Зараховано!» або «Видано Карамель −7 ✦ (Залишок: 16 ✦)»; зникає за 3.5–5 с; `aria-live="polite"`. Стилізований під Genshin-сповіщення із золотим кантом та неоновим сяйвом.

### 3.7. Службове

Перший запуск: екран вітання з великим золотим Примогемом `iconPrimogem(64)`, назвою «Зоряний клас» шрифтом `--font-fantasy` та підказкою звернутися до вчителя за QR-карткою. Кнопка «Це не я» (`.btn-genshin-crimson`, очищає збережений профіль). Офлайн: акуратний золотаво-бронзовий банер «Немає зв'язку, показано збережені дані».

## 4. Екрани вчителя (`teacher/index.html`)

### 4.1. Вхід

Email/пароль (або Google). Стан «Немає доступу», якщо користувача немає в `admins`.

### 4.2. Сканер (головний)

```
┌──────────────────────────────────────┐
│  [  видошукач камери з 4 золотими    │   ← .scanner-container та .scanner-overlay
│     кутовими дужками-прицілами  ]    │     з золотим кантом
│  Наведи на QR учня                   │
│  [Вибрати учня зі списку]            │
│  Підказки: бекап · 3 учні з 17 ✦ ... │
└──────────────────────────────────────┘
```

### 4.3. Панель учня

```
┌──────────────────────────────────────────────┐
│  ← До списку   Лис-07 (І. К.) ✏️    📷 Сканер│   ← кнопки у золотому стилі
├──────────────────────────────────────────────┤
│ Рівень: Учень 3-го рангу       [📱 QR учня]  │   ← .surface-card з золотим кантом
│ 23 ✦ (величезний шрифт Cinzel)               │
├──────────────────────────────────────────────┤
│ Оцінки з щоденника:                          │
│ [7]  [8]  [9]  [10]  [11]  [12]              │   ← плитки сузір'їв (.grade-btn)
│ Вибрано: 11, 9 → +8 ✦ (+3 ✦ «Зростання»)     │   ← підсвітка cyan glow
│          [  Зарахувати оцінки  ]             │   ← .btn-genshin-gold
├──────────────────────────────────────────────┤
│ Обмін на нагороди:                           │
│ [Карамель 7 ✦]  [Желейка 12 ✦]  [ще 17 ✦]    │   ← недоступні з підписом залишку
│ Ручні квести («Внесок у клас»):              │
│ [iconContrib  Внесок у клас +2 ✦]            │
├──────────────────────────────────────────────┤
│   [📷 Наступний учень]   [👥 До списку]      │
└──────────────────────────────────────────────┘
```

Поведінка: після «Зарахувати» панель лишається відкритою для видачі; тап на нагороді = списання без діалогу; знизу спливає повідомлення «Видано Карамель −7 ✦ · Скасувати (10 с)»; модальне вікно учнівського QR у стилі квестового пергаменту (`.genshin-modal-content`). Через 60 с бездіяльності або «Наступний» повернення до сканера; м'яке застереження про повтор.

Для замовлення (`R`): зверху панелі з'являється виділений банер із вибраною позицією та золота кнопка видачі замовлення.

### 4.4. Список учнів

Таблиця: псевдонім, (ініціали з довідки), баланс, рівень; пошук; фільтр «Показати архівовані»; дії: відкрити панель, друк картки, коригування, перевипуск, архівація.

### 4.5. Адмінпанель

Екрани перелічені в `09-admin-panel.md`.

## 5. Тексти (приклади для `i18n/uk.js`)

| Ключ | Текст |
|---|---|
| `scan.unknown` | Це не картка Зоряного класу |
| `scan.noCamera` | Немає доступу до камери. Дозволь камеру в налаштуваннях браузера або вибери учня зі списку |
| `order.expired` | Замовлення не на сьогодні |
| `credit.done` | Зараховано +{n} ✦ |
| `credit.repeat` | Щойно вже зараховували {g}. Підтвердити ще раз? |
| `redeem.done` | Видано {item} −{n} ✦ |
| `redeem.insufficient` | Ще {n} ✦ |
| `redeem.cooldown` | Знову через {days} дн. |
| `redeem.stock` | Закінчилось |
| `offline.teacher` | Немає зв'язку, спробуйте ще раз |
| `undo` | Скасувати |
| `receipt.credit` | +{n} ✦ |
| `receipt.redeem` | Отримано {item} −{n} ✦, залишок {left} ✦ |

Відмінювання: `plural(n, ['зірка','зірки','зірок'])`, `plural(days, ['день','дні','днів'])`. Не конкатенувати вручну.

## 6. Доступність

- Цілі дотику ≥ 48×48 px; відстань між кнопками ≥ 8 px.
- Не лише колір: іконки й текстові статуси.
- `aria-live="polite"` для балансу й квитанції; `aria-label` для іконок; фокус-кільця.
- Усі функції вчителя доступні з клавіатури (десктоп).
- Контраст ≥ 4,5:1; `prefers-reduced-motion` поважається; `prefers-color-scheme`.
- Мінімальний розмір тексту 16 px; масштабування сторінки не блокується.

## 7. Стани

Для кожного екрана реалізувати: завантаження (скелетон), порожній стан, помилка мережі (з кнопкою «Повторити»), офлайн (банер), «немає доступу». Помилки для дитини прості й добрі («Щось пішло не так. Спробуй ще раз»), для вчителя конкретні.
